# 🌾 AgroTrade Intelligence — Frontend

**AgroTrade Intelligence** is a web-based agricultural market intelligence platform that provides users with data-driven insights into crop prices, profitability, seasonal trends, market conditions, and crop recommendations.

This repository contains the **frontend application**, built with React.js and Vite. It provides the interactive user interface and communicates with the Flask-based backend API to obtain machine learning predictions and analytical results.

## 🌐 Live Application

**Frontend:**
https://agrotrade-frontend.vercel.app/

**Backend API:**
https://agrotrade-intelligence-backend.onrender.com

---

## 📌 Project Overview

Agricultural decision-making often involves analyzing multiple factors such as crop prices, market conditions, seasonal patterns, and expected profitability.

AgroTrade Intelligence provides a unified web interface where users can interact with these insights through an easy-to-use dashboard.

The frontend is responsible for:

* Collecting user inputs
* Displaying agricultural information
* Sending prediction requests to the backend
* Presenting prediction results
* Providing analytical dashboards
* Displaying market and seasonal insights
* Providing crop-related recommendations

---

## ✨ Features

### 🌱 Crop Price Prediction

Provides an interactive interface for entering agricultural parameters and retrieving crop price predictions generated by the machine learning backend.

### 💰 Profitability Analysis

Displays information related to expected agricultural profitability to support data-driven decision-making.

### 📊 Agricultural Analytics

Provides dashboard-based views for exploring agricultural and market information.

### 📈 Seasonal Analysis

Helps users explore seasonal patterns and crop-related trends.

### 🏪 Market Comparison

Provides an interface for comparing market and crop-related information.

### 🌾 Crop Recommendation

Presents crop-related recommendations based on the available agricultural data.

### 🔗 Backend Integration

Communicates with the Flask backend through HTTP/API requests to access machine learning prediction functionality.

### 📱 Responsive Interface

Designed to provide a usable experience across different screen sizes.

## ⚙️ Getting Started

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/kumudsalunke26/AgroTrade-Intelligence-Frontend.git
```

### 2. Navigate to the project directory

```bash
cd AgroTrade-Intelligence-Frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The Vite development server will provide a local URL in the terminal.

---

## 🔌 Backend Configuration

The frontend communicates with the deployed Flask backend:

```text
https://agrotrade-intelligence-backend.onrender.com
```

If running the backend locally, configure the frontend API endpoint to point to the local Flask server.

A typical development setup is:

```text

       │
       ▼

```
